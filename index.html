# The Lean Startup — Simple Summary

**Book:** *The Lean Startup*

**Author:** Eric Ries



## Introduction


*The Lean Startup* teaches entrepreneurs how to build a business in a smarter and less risky way.
Its main idea is simple: **don't spend a lot of time and money building something before knowing whether customers actually want it.**

Instead, create a basic version, show it to real customers, learn from their feedback, and improve it.

## 1. Start With a Problem


A successful startup should solve a real problem.

Before building a product, ask:

* What problem am I solving?
* Who has this problem?
* Will people actually use my solution?
* What will make my product useful?

A good idea is not enough. **Customer need is more important than the founder's assumption.**

## 2. Build — Measure — Learn


This is one of the central ideas of the book.

### Build

Create a simple version of your product.

### Measure

Observe how real users react to it.

### Learn

Use the results to understand what customers actually want.

Then repeat the process.

**Build → Measure → Learn → Improve**

 This helps a startup learn quickly instead of blindly guessing.

## 3. MVP — Minimum Viable Product


An **MVP (Minimum Viable Product)** is the simplest version of a product that can help you test an important business assumption.

For example, if you want to create a food-delivery app, you don't necessarily need to build a huge app first. You could start with a simple system that allows a small number of customers to order from a few restaurants.

The purpose is **not to create a perfect product**. The purpose is to **learn whether the idea works**.

## 4. Don't Assume — Test


Entrepreneurs often make assumptions such as:

"People will definitely buy this."

The Lean Startup approach says: **test that assumption with real customers.**

Real customer behaviour can teach you more than opinions or guesses.

## 5. Innovation Accounting


A startup needs useful measurements to understand whether it is actually improving.

Instead of focusing only on things like total downloads or followers, look at meaningful results such as:

* How many people use the product?
* How many return?
* How many become paying customers?
* Which changes improve customer behaviour?

The goal is to measure **real progress**, not just impressive-looking numbers.

## 6. Persevere or Pivot


After testing an idea, a startup has an important decision.

### Persevere

Continue with the current direction because the evidence shows that it is working.

### Pivot

Change an important part of the strategy because the evidence shows that the current approach is not working.

A pivot is not simply giving up. It means **learning from evidence and changing direction intelligently.**

## 7. Continuous Improvement



A startup should keep experimenting and learning.

Instead of asking:

**"How can I build everything perfectly?"**

ask:

**"What is the fastest useful experiment I can run to learn something important?"**

This can save time, money and effort.

## 8. Main Lesson



The biggest lesson of *The Lean Startup* is:

**Build less blindly, test more, learn faster, and improve continuously.**

 A startup does not become successful simply because it has a great idea. It becomes stronger when the entrepreneur understands customers, tests assumptions, learns from evidence and adapts quickly.

## Simple Example

Imagine you want to start an app that helps students learn English.

Instead of spending one year building a huge application, you could first create a small version with:

* 20 vocabulary lessons
* simple quizzes
* progress tracking
Give it to a small group of students.

If students use the vocabulary lessons but ignore another feature, you have learned something valuable. You can improve the useful parts and change or remove the less useful ones.

This is the Lean Startup mindset.

## Final Takeaway

**Don't build a huge business based only on your assumptions. Start small, test your idea with real customers, measure what happens, learn from the results, and keep improving.**

That is the core mindset behind *The Lean Startup*.
